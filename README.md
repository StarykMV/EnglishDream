# EnglishDream

Ігровий тренажер англійської мови для українців.

- **Шлях уроків** — 7 часів простою мовою з тренажерами, зірками і досвідом.
- **Слова** — понад 900 розмовних слів у 33 темах, з озвучкою.
- **Серія днів і ціль на день**, звуки, конфеті.
- Прогрес зберігається у браузері.

Відкрити: файл `index.html` — це весь сайт, без збірки й залежностей.
